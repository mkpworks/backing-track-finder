Embed

Use the finder on another site

Add this markup. The script loads the catalog from this site, draws inside a shadow root, and does not restyle the host page.

<div id="backing-track-finder"></div>
<script src="https://mkpworks.github.io/backing-track-finder/embed.js" defer></script>

Optional attributes: data-theme (light or dark), data-accent (a hex color), and data-height (a max height). data-channel, data-practice (or data-instrument), data-style, data-key, data-progression, data-kind, data-omitted, data-duration, data-tempo-min, data-tempo-max, and data-quick preset those filters. Any element with data-backing-track-finder mounts too. Call BackingTrackFinder.mount(element, options) for the same options in script. Open on YT Trainer stays in the same tab when this finder is embedded on ytmusictrainer.com.
